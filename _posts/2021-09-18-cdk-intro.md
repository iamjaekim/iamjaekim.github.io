Hello, AWS CDK?

Hello, I'm Jae Wook Kim. Today's topic is to introduce [CDK](https://docs.aws.amazon.com/cdk/v2/guide/home.html), another resource provisioning tool from AWS.

![AWS-CDK](../images/2021-09-17-cdk-pt1/cdk.png){: width="100%" height="100%"}

AWS CDK stands for Cloud Development Kit. It is a tool that helps you define cloud resources using conventional programming languages, rather than YAML or [HashiCorp's Terraform]({% link _posts/2020-11-22-terraform-pt1.md %}).  
For example, if you are a developer who knows how to use one of the supported languages and you want to write code to create cloud resources, CDK could be the tool for you. Apart from this, having basic knowledge of AWS is essential and will be very useful when defining resources with code.

As of `2021-09-18` when this post is written, the languages officially supported by AWS CDK are as follows:

- TypeScript
- JavaScript
- Python
- Java
- C#

Also, before starting, an AWS account is required, and basic permissions and configurations for using the AWS CLI must be set up.

## Install CDK

There are many ways to install CDK. The most common method, as described on the official website, is to install it on your system using NPM (Node Package Manager).
If NPM is already installed, you can easily install it with the command below.

```bash
# https://docs.aws.amazon.com/cdk/v2/guide/cli.html
npm install -g aws-cdk
```

If you don't have NPM yet, you might be able to install it via your OS's package manager.
For instance, on a Mac, you can also install it via brew.

```bash
# https://formulae.brew.sh/formula/aws-cdk
brew install aws-cdk
```
